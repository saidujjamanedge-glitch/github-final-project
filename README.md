# Introduction to Git and GitHub - Final Project

## Simple Interest Calculator

This is a simple interest calculator application built as part of a micro-finance startup project. It calculates simple interest given the principal amount, annual rate of interest, and time period in years.

### Project Name
Simple Interest Calculator

### Description
A calculator that calculates simple interest given principal, annual rate of interest and time period in years. This project demonstrates the use of Git and GitHub for version control and collaboration.

### Input Parameters
- **p**: principal amount
- **t**: time period in years
- **r**: annual rate of interest

### Output
- **simple interest** = p * t * r

### Usage
```bash
./simple-interest.sh
```
